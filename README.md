# exoplanet-app

To globally visit the app, go on the website: https://trigospace-exoplanet-app.streamlit.app/ (if it is still available and not sleeping)

To locally run the app:

1. Install the exoplanet_app folder (you can use git clone or physically download it)

2. run "pip install -r requirements.txt" on your command prompt

3. run "streamlit run testingapp.py"
